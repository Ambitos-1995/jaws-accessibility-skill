## 1) WCAG 3.0 status

- WCAG 3.0 is a W3C Working Draft.
- It is not a W3C Recommendation and not a legal compliance baseline.
- Current public draft date: 2026-03-03.

## 2) How to use this file

Use this material only for:
- roadmap planning
- design-system strategy
- internal capability building

Do not use this file as evidence of legal compliance.

## 3) Watchlist

Track these changes over time:
- scoring model evolution (outcome-based model)
- readability and cognitive accessibility treatment
- contrast model discussions (for example APCA references in ecosystem discussions)
- migration implications for procurement and QA pipelines
- EN 301 549 V4.1.0 publication and the separate EU Official Journal harmonization step; neither a draft nor an approval-stage artifact is automatically a legal baseline

WCAG-EM 2.0 is no longer a future draft. W3C published it as a final Group Note on **2026-07-23**. Use it for formal evaluation methodology as routed in `jaws-audit-methodology.md`; it does not add or replace WCAG success criteria.
